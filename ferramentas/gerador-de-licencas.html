Kontor Gestão Empresas – Gerador de licenças

Ferramenta só sua. Funciona offline, sem enviar nada para a internet. Guarde a chave privada em local seguro e nunca a envie a ninguém – quem a tiver gera licenças.

1. Gerar o par de chaves (uma única vez)

2. Emitir código de ativação

3. Código de acesso de suporte (usuário master KONTOR)

O usuário KONTOR não tem senha. Para entrar no sistema de um cliente, gere aqui um código para o computador dele: na tela de login, use o usuário KONTOR e cole o código no campo senha. O código só funciona naquele computador e expira sozinho (no máximo 24 horas).
